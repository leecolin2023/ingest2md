# Deep Read｜“无限画布”AI 创业团队如何追问候选人的 Agent 能力

面试由初创公司技术负责人主持，候选人介绍自己参与跨境电商 AI 客服、RAG、知识库、运营生图、视频等项目。对方追问候选人具体负责哪些端到端环节，如何设计生成、审核和数据追溯。交流逐渐落到 Agent 行为与真实系统能力，而不只是列举 LangGraph、RAG 等术语。

面试官尤其关注**用户能否看到一次 AI 生成结果背后的证据和过程**，例如最终输出使用了哪些检索材料、模型输入和执行日志，以及多步骤内容生成如何让用户修改。候选人表示可追踪 Prompt、检索内容与调用结果，但缺少这家公司实际产品中可以直接复用的完整展示。

随后创业团队介绍自身产品：用统一的“无限画布”工作空间承载文字、图片、音频和视频生成、编辑与工作流。传统创作者需要在多个模型网站、剪辑软件与文件夹之间切换；团队希望将工具和素材连接成一次完整的内容生产体验。

公司讲述了订阅收入增长、融资和模板积累，称已沉淀经过市场验证的内容工作流模板，下一步要让用户以自然语言选择模板、让 Agent 自动组织多步骤生产，并保留可控制、可修改的中间结果。收入和团队规模数字均为面试官口述，未经外部审计。

结尾谈到岗位薪酬、创业风险、是否远程、候选人的职业方向以及第二轮 CEO 面试。直播复盘明显带有对早期 AI 创业机会的乐观判断。

这场面试的认知中心是：**从单点模型生成功能，走到跨模态创作工作流、模板复用、用户控制和可追踪过程**。
