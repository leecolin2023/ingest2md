> 来源：`output/20261025__30 自媒体运营Agent 3_ev/content.md`（7分15秒）。Deep Read V6.4，保留话术与事实性质。

这一节延续上一段的成本核算，讲者通过向 AI 询问报价，示意如何收集豆包文本模型、图片生成与视频生成服务的单位价格。他口头提到若干价格，例如输入 Token 比输出 Token 便宜、图片按张、视频按秒计价，并明确说只是参考价，不保证准确。

之后他比较**官方 API**、第三方低价 API 供应商，以及通过自动化模拟网页交互的所谓“逆向”渠道。他举例称部分生成图片的成本可以很低，但认为这类方式生成效果可能不及官方接口。

再转向视频生成，他声称某视频平台对普通客户会暗中降低生成质量，并讲述有人花数百万元购买专用通道的故事。但讲者同时对报价数字出现犹豫和自我修正，无法提供可核实证据，因此这些属于**个人传闻和猜测**，不能当作厂商已证实的经营事实。

最后他将这些轶事作为面试时可讲的故事，强调让项目叙述生动。视频中“自己没验证的传闻可以用于讲故事”的态度应与可审计的项目事实区分开来。整体是成本认识与求职话术的一次混合讨论，而非真实定价调研报告。
