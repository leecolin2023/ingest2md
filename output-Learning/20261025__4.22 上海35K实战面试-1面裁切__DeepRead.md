# Deep Read｜上海 35K 一面：AI 工作流与企业转型

> 来源：output/20261025__4.22 上海35K实战面试-1面裁切/content.md（约56分42秒）。Deep Read V6.4，Coverage-Preserving。

候选人讲述跨境电商企业的 AI 转型，包括客服、商品知识库、文案和图片生成、MCP 类服务及数据中台。面试官首先追问企业为何开始用 AI，候选人归因于电商经营压力与降本增效需求。之后问题进入精确商品匹配：用户问某个 SKU 时，纯语义召回可能串到另一规格，候选人提出混合检索、商品 ID 元数据过滤及检索权重调整。

面试官继续关注一次用户请求如何进行端到端追踪，候选人建议由网关生成 Request ID，把 Prompt、检索片段、模型输入输出和调用日志串起来。随后双方比较确定性工作流和自主 Agent：固定内容生产可以由多个节点和条件分支控制，模糊问题则可能交给模型判断需要调用什么工具；对多 Agent 并发，讨论了共享状态的竞态问题。

面试官以员工照片是否戴工牌、拍摄姿态是否正确等图像合规问题考察如何把业务标准转换为模型输出与判定规则。两人又谈 AI 编码、统一业务数据中心，以及十多年的企业软件如何沉淀员工经验、用 Skill 和 Markdown 规范支持重构。尾声介绍上海传统软件公司的技术背景、招聘计划、城市、薪酬与后续轮次。

本场材料不只有技术术语，更强调真实公司在选择 AI 任务时如何区分可枚举规则、模型判断、业务验证和系统交付。
