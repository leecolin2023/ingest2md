# Deep Read｜西安 Agent 面试中的销售教练与端到端交付

> 来源：output/20261025__7.20 西安35k Ai agent/content.md（18分06秒）。Deep Read V6.4。

候选人说自己在电商小型技术团队覆盖前端、服务端和运维，近两年着重参与企业 AI 转型。他以销售咨询为例说明：AI 客服不能只是从知识库找一句话答复，还要结合客户需求、商品属性和销售策略引导对话。

候选人提出**销售教练**模式：企业运营人员分别模拟客户和销售，让系统从示范沟通中学习企业口吻；真实客服则结合用户话语和商品信息逐步回应。他又介绍按 SKU 组织的多种知识数据：文字问答、图片标签与描述、视频片段说明，不同媒体共享商品关联键，查询时先做意图识别和商品过滤。

课程还提到销售考核、直播内容切片、业务数据清洗，以及早期曾尝试微调销售模型、后因训练成本及版本更新速度而降低优先级的取舍。

面试官介绍西安团队规模较小，接到新需求时工程师可能需要独立澄清、设计并完成前后端与 AI 接入，减少交接损耗。双方讨论候选人的综合技术能力是否适合这种模式，和未来业务可能由单个模块扩展为完整 AI 电商生态的方向。

全场强调产品业务与端到端交付，不能只归纳成对单个 Agent 框架的问答。
