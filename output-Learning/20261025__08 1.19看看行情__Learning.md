# Learning｜为什么 AI 应用开发与模型研发是不同职业路线？如何核查招聘机会？

> 原稿：output/20261025__08 1.19看看行情/content.md。Learning V0.7.0；独立 Review 隔离未验证。

**AI 应用工程师**通常围绕真实业务需求集成模型、RAG、Agent、数据库、权限和可靠性，重点在系统方案及业务交付。**模型训练与推理研发工程师**则更侧重训练算法、模型架构、推理性能、GPU/NPU 工程或模型评价。两个岗位可以交叉，但简历要求、面试方式和日常责任不同。

判断招聘内容时不能只看“AI”二字，也不能看见 Java/分布式就断言不是 AI。要看代码和系统主要服务什么业务、技术负责人是谁、真实团队是否存在、交付责任和性能标准是什么。

对跨城市求职，招聘搜索可以帮助发现岗位，但必须记录搜索时间、过滤条件、职位链接及重复项，才适合推断趋势。视频中武汉、郑州、贵阳等地工资只是当时演示的若干样本，不宜套用为今天的薪酬数据。

技术知识方面，讲者最后区分 Chunk 大小和回复长度是有用的：向量检索拿回 512 Token 的某一片段，只是送给 LLM 的**证据上下文**，模型生成多少 Token 还取决于问题、提示词和输出约束。

求职准备应以真实项目经历、相关技术理解、面试反馈为依据；不要用虚构任职、夸大成果或不实离职理由替代长期能力积累。
