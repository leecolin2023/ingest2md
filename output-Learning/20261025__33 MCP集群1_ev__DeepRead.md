# Deep Read｜讲者所设想的 MCP 服务网关承担哪些职责

> 来源：`output/20261025__33 MCP集群1_ev/content.md`（5分08秒），Deep Read V6.4。

讲者将“项目五 MCP 集群”划分为四类能力：**MCP 网关、模型相关服务、RAG 相关服务、Prompt 管理**，另外也可以扩展通用服务。他设想公司有八个业务项目、几十甚至上百项工具服务，需要一个统一管理入口。

本节主要展开网关的四项职责：

**认证**：验证请求确实来自已授权的公司项目，而不是任意外部调用者。

**日志**：一条业务可能连续调用多个 MCP 工具，需要知道每次调用的参数、路径、结果和错误位置，方便故障排查。

**配额**：不同项目或工具的 Token、调用次数等资源消耗应有上限，防止一个项目占用全部公共额度。

**路由和授权**：假设有一百个服务，项目 A 可能只能使用其中二十个，网关需按项目权限决定哪些工具可以被发现和实际调用，而非让所有项目默认拥有全集权限。

讲者要求学员回到具体业务想清楚配额多少、业务角色是谁、哪些服务要开放，形成可向面试官解释的闭环。视频没有演示完整的 MCP 协议实现或网关生产部署。
