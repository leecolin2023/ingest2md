# Deep Read｜如何从大型题库出题并评价销售沟通能力

> 来源：output/20261025__39 销售考核系统2_ev/content.md（9分45秒），Deep Read V6.4。

讲者先提出一项难题：真实客户聊天与考试回答的形式不同，直接用相似度计算考题标准答案可能出错。客户问“课程多少钱”，真实销售可能先解释价值再报价；考生对情景题的回答则常是“我先了解需求，再说明价值”。两段字面不同，但沟通策略可以一致。

因此，在**出题侧**，讲者建议先给题目打“价格、成交、个人情况、产品特点”等标签，由大模型辅助制定试卷大纲，如成交三题、产品两题，再按标签从数据库过滤到少量候选题，最终随机抽取，而不是对十万条数据直接让模型无约束生成。

在**评分侧**，评分规则应包括销售沟通思路与业务事实；可以通过意图识别和 Query 改写，把考题、考生答案与知识库里的概念对应起来。他还建议将考试设计成面对真实客户的情景对话，交代用户背景，使作答更贴近训练资料。

整段材料的认知结构是：题库按标签组织 → 大纲决定考核覆盖 → 数据库筛题 → 考生针对完整场景答复 → AI 结合明确标准和检索内容评分。讲话者没有展示自动评分与人工一致性的证据。
