# Learning｜LoRA 和 QLoRA 为什么减少显存？

> 原稿：output/20261025__42 模型微调3_ev/content.md，Learning V0.7.0；独立 Review 隔离未验证。

全参数微调要存储原始权重、梯度以及优化器状态。LoRA 冻结大多数底座权重，在部分矩阵上加入可训练的低秩适配器，因此需要更新和保存的参数更少。

QLoRA 将**冻结的基础模型权重以低比特量化形式存储**，训练仍通过适当精度的计算更新 LoRA 适配器。它并不是把整个训练过程变为 4-bit 整数计算，也不是简单地把“LoRA 的参数量再除以四”。

是否牺牲任务效果，要由同一业务持出集比较；不能断言 LoRA 一定“无损”、QLoRA 一定显著降质。影响实际显存的还包括序列长度、激活内存、Batch、梯度累积、优化器等。

因此，先根据真实硬件判断能否容纳底座和训练状态，再选择普通 LoRA 或 QLoRA，而不是按“本地/云端”的标签机械分配。
