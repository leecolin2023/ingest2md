# Learning｜如何比较模型 API 成本、质量与供应链风险？

> 原稿：`output/20261025__30 自媒体运营Agent 3_ev/content.md`。Learning V0.7.0；独立 Review 执行隔离未验证。

## 模型价格为什么不能只看每百万 Token

同一业务任务可能调用文本生成、图片生成、视频生成、审核模型与存储服务。成本应按各自计费单位统一换算，例如：

`任务成本 = 输入Token费 + 输出Token费 + 图片生成费 + 视频生成费 + 其他调用及重试成本`。

比较模型时需要固定图片尺寸、视频时长、画质等级、候选数和失败重试策略，否则价格更低可能只是因为生成规格不同。价格有时效性，必须从服务商当前正式价格表核对。

## 非官方接口为什么不是单纯“便宜”

第三方代理和网页自动化往往引入账号授权、服务条款、数据安全、隐私、稳定性、日志留存和追溯责任问题。金融与企业业务尤其应优先考虑正规 API、合同承诺和数据处理边界。绕开正常 API 配额和网页限制，也不是长期可靠的工程方案。

## 质量怎么做可比实验

为文字、图片或视频制定相同输入集合，记录质量评估、端到端完成率、成本、P95 延迟和失败样例。若怀疑不同通道质量不同，要在相同参数和样本条件下反复测量，避免把随机波动理解成服务商“暗中降质”。

讲者提供的厂商价格、专用通道金额及“降质”说法均缺少可靠的当前证明；学习时更有价值的是掌握**可比口径、成本归集与数据安全判断框架**，而非记住未经核实的数字。
