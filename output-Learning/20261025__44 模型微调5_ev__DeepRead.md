# Deep Read｜微调结果该从人工盲评走向业务成效

> 来源：output/20261025__44 模型微调5_ev/content.md（9分58秒），Deep Read V6.4。

讲者提出“本地和云端微调怎样才算 OK”。他将本地实验定位为低成本验证：训练前预留一部分优质样本不参与训练，让未微调和微调模型回答同样问题，遮蔽模型身份后请人员评价口吻自然程度和 DPO 倾向。他称此为“双盲测试”，但原文还将样本多寡的比较混入说明，实验条件并不完整。

云端则要准备更广泛的测试问题，并使用云厂商模型评测工具，比较微调后模型与未微调底座的质量。他依次提出多轮对话是否保持既定风格、未知知识是否出现幻觉、偏好训练目标是否达成。

最后，他强调技术评分不够，真正重要的是实际业务结果：销售转化率、投诉率、人工返工等。如果模型虽然“更像人”，却使客户投诉增加、成交下降，就没有体现微调的业务价值。

整个材料逐层推进：**本地持出集盲评 → 云端对照与多轮测试 → 幻觉和偏好边界 → 真实业务指标 → 判断投入是否值得**。课程没有报告已完成的实验指标。
