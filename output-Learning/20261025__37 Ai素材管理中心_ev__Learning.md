# Learning｜多模态素材中心怎样让 RAG 按语义找到图片与视频？

> 来源：`output/20261025__37 Ai素材管理中心_ev/content.md`。按 Learning V0.7.0；独立 Review 执行隔离未验证。

一个媒体资产需要至少保存 `asset_id`、`sku_id`、`media_type`、`url`、`description`、`tags`、`version` 和审核状态。文字描述和标签可以转成 Embedding，供自然语言检索；商品 ID 与媒体类型则用于精确过滤。

对于两小时直播切片，先通过 ASR 获取对应时间段语音，再结合时间戳和必要的画面信息生成摘要，标明这段介绍了哪个商品、什么功能、有哪些促销说法。再由审核机制校正易错商品名与过时价格。检索命中后，前端拿到的是经过权限验证的媒体 URL，而不是让语言模型“想象一个视频地址”。

这一架构主要是**文本驱动媒体检索**。如果用户问“找出画面中展示红色外壳的镜头”，单靠 ASR 文本未必够用，需要实际视觉索引或更细的元数据。

验收时看商品 ID 是否正确、引用的片段时间戳是否匹配、素材是否可访问且已审核、同一素材的新旧版本是否能正确失效。素材中心的价值在于为多个 Agent 共享可信媒体资产与索引，而不只是堆放文件。
