## 先用招聘例子解释神经网络

讲者希望听众掌握 LLM 原理，以便理解 API 参数、模型性能和技术面试。他从 N-gram 的共现统计过渡到神经网络，用“筛选简历”说明输入特征与权重的关系：学历、经验、技能经过多层计算，产生候选人得分。这个类比强调模型并非直接查表，而是用大量参数组合输入特征。

## 从预测错误到参数更新

**前向传播**是根据输入和权重计算输出；**损失函数**比较输出与预期目标；**反向传播**利用导数和链式法则计算各参数对损失的影响；**梯度下降**再沿降低损失的方向调整参数。

讲者用“招到员工后发现不合适”表示损失、用“山坡向下走”解释梯度下降、用简单函数求导解释参数变化敏感度。他特别强调反向传播不是把前向程序倒放，而是求梯度。

随后介绍**过拟合和 Dropout**：当模型过度依赖训练集偶然特征，例如错误地把“穿格子衫”与员工质量挂钩，就可能泛化失败。训练时随机屏蔽部分神经元连接，是用于降低这种依赖的一类正则化办法。讲者对学习率的口头描述有时说成“调整参数的频率”，其主要想表达的是更新步幅不能过大或过小。

**数据标注**提供监督目标，不等于反向传播本身。讲者以“标明猫还是狗”的标签与模型训练时按错误更新权重的区别，说明两者分处数据准备与优化环节。

## 训练流程与参数规模

他将训练概括为数据准备 → 前向传播 → 计算损失 → 反向传播 → 参数更新，并提到预训练与后续微调。接着讨论模型参数规模增长和硬件压力，但关于模型发展速度、训练费用与本地部署价格的数字都属于即席估算，未提供相同条件的成本口径。

## MoE、下一词预测与蒸馏

讲者介绍 MoE（混合专家）时，以“按任务路由不同专家”解释稀疏激活：拥有很多总参数不代表每次 Token 计算都用上全部专家。这降低部分推理计算，但路由、训练和并行调度更复杂。

再用“床前明月光，疑是地上霜”说明语言模型根据上下文预测后续 Token 的过程；他认为已有大量诗歌可能在预训练中出现，但对于专有、最新或小众内容仍可能需要 RAG 提供外部证据。

最后是**蒸馏**：让较小模型学习教师模型输出、分布或行为，类比直接向资深股民学习经验而不必经历全部原始数据。他强调低延迟、移动端和成本敏感场景的潜在价值，未用实验支持具体压缩比例。
