# Learning｜销售 Agent 和普通知识库问答，差别在哪里？

> 来源：output/20261025__7.20 西安35k Ai agent/content.md。Learning V0.7.0；独立 Review 调用隔离未验证。

知识库问答的基本任务是从可信资料里找到与当前问题相关的答案。销售 Agent 还要在用户授权与商业规则下维持上下文、澄清需求、选择素材以及提出下一步选项。这不意味着可以隐瞒用户明确索取的价格，也不意味着销售目标高于事实准确性。

例如客户问“有没有适合跑步的耳机”，系统先确认商品类别和用途；查权威规格与售后说明；需要时展示该 SKU 的图片和视频；确认购买意向后再提供业务系统生成的下单链接。

商品 ID 保证不串商品，Embedding 负责语义近似，结构化数据库保存当前价格库存，业务 API 执行真实订单动作。模型微调可以影响对话风格，但不能替代这些数据与权限约束。

对于小团队端到端交付，还要具备需求澄清、接口、UI 状态、故障排查、日志、部署和质量评测能力。真正的产出是一个用户可完成的业务过程，不是一个展示过的模型回答。
