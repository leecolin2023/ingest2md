# Deep Read｜字节外包技术面与其后直播复盘

> 来源：output/20261025__3.9 字节外包-裁切/content.md（约44分43秒，后半段为直播授课）。Deep Read V6.4，Coverage-Preserving。

候选人继续介绍电商背景、AI 客服和运营生成系统。面试官从数据清洗切入，要求讲清 WhatsApp 历史销售对话如何导出、分成会话、按规则过滤、进行人工清洗，并制作知识库/微调数据。候选人说明数据中台如何筛选高质量会话，但多个数字和清洗比例只是口述。

面试官随后追问开发语言、FastAPI 的某种“同步/异步桥接”（ASR 原词不明）、向量检索的相似度计算以及为何使用不同相似度度量。候选人的若干回答对 cosine、L2、相关曲线的概念存在混杂，还坦承简历里某些技术术语是 AI 写的、自己并不十分了解。

对 LoRA/QLoRA，候选人使用房屋装修、投影等类比解释低秩和量化，却没有展示微调日志或配置。对 LangGraph 的 Subgraph 和 Checkpoint，则能说明子图封装流程、存储执行状态与中断恢复。对 Agent 评测，他区分忠实度和切题程度，主张保存检索证据和参考答案。

技术面结束后，直播讲者评价对方追问较少，又举另一场高强度技术面的细节要求为对比，例如 Redis 缓存击穿、限流熔断、服务迁移和按 Query 动态路由模型。

后半部分几乎转为招生推广、学员工资案例、零基础学习周期、技术栈选择和资料保密规定。这些独立主题不能误认为面试官提出的技术问题，培训价值与薪资案例也未被独立验证。

整个材料展示了**项目自述 → 数据和 API 基础 → 向量/微调/Agent 机制 → 评测 → 面试差距与课程推广**。
