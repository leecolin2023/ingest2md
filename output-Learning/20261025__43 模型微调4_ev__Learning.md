# Learning｜Epoch、Batch、Learning Rate、LoRA Rank 与 Alpha 如何选择？

> 原稿：output/20261025__43 模型微调4_ev/content.md；Learning V0.7.0，独立 Review 隔离未经验证。

Epoch 是训练集完整经过模型的次数，多轮训练有助于拟合，但可能过拟合；Batch Size 决定每次梯度更新使用多少样本，也会影响显存需求；学习率控制参数更新幅度，过高容易不稳定，过低可能收敛慢。

LoRA Rank 决定适配器低秩矩阵的容量，越大通常可表达更多变化但会增加参数量；Alpha 是 LoRA 增量的缩放因子，要结合 Rank 及具体实现理解，并不是越大越强。

以同一条销售客服训练任务为例，应先保存数据集、底座模型、随机种子和基线配置，在固定的持出集上评价风格准确性与事实错误。调参过程可以改变一两个因素，比较效果与成本，而不是先填写漂亮的数字再想理由。

视频里的本地 Rank 64、Alpha 128，云端 Rank 32、Alpha 64，以及不同轮次和学习率，均无真实实验支撑。它们适合作为认识参数的教学例子，不适合作为生产验收结论。
