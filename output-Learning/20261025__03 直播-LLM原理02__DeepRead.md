## 从 RNN 限制到 Transformer

讲者首先提到早期 RNN 顺序处理及长距离依赖困难，将 Transformer 介绍为可以在训练阶段更好地利用 GPU 并行、让不同位置建立相互联系的架构。词序仍很重要，因此他用正弦和余弦解释位置编码，强调既要表达位置，又要能让模型利用位置间关系。他还把相对位置泛化全部归因于正余弦周期性，这属于课堂简化。

## Attention、FFN、残差

**自注意力**用于建立序列中不同位置的关联，讲者称之为“横向信息流动”；**前馈网络 FFN** 对每个位置的表示进行非线性变换，他类比为存储知识的“纵向深化”。例如一段话提到巴黎和埃菲尔铁塔，注意力让位置相互影响，FFN 参与形成更丰富的内部表示。

接着解释**残差连接**：深层模型经过许多变换后，原始信息和梯度传播可能更困难；残差路径使输入信息有一条可传递的通道。他用文件经过一百人修改的类比帮助理解。

## 编码器、解码器和生成方向

讲者区分 GPT 类自回归解码器、双向编码器以及编码器—解码器结构。因果 Mask 使生成下一个 Token 时只能利用前面已知内容。多头注意力不是与“单向”冲突的概念：一个表示多个注意力子空间，一个规定每个位置允许看哪些位置。

他以“床前明月光”接续诗句说明下一 Token 预测，并把无标签大语料预训练、SFT 指令微调、奖励模型与基于人类反馈的强化学习作为能力形成阶段。部分内容把 RLHF 简化成逐次“说错就打、反向传播改参数”，属于方便理解的口头类比。

## RAG、涌现与长上下文

讲者认为预训练记忆并不能覆盖一切新事实，RAG 在推理时提供外部资料，而不是再次训练模型。随后提到参数规模变化与所谓“涌现”能力，强调能力增长并不按参数量线性增长。

关于长对话，他认为历史 Token 会累积并受上下文窗口限制，有些应用通过摘要或压缩保存旧信息，因而丢失细节；于是建议摘要与 RAG 结合，保留关键事实。相关窗口数值随模型版本变化，不能当当前通用配置。

## 图像、音频和视频如何接入序列模型

讲者用图片分块、视觉编码器将图像变为特征表示，音频通过采样、频谱或分帧变为可处理表示来解释多模态输入。他特别强调视频不仅有画面，还有声音和时间维度，需要使视觉、听觉内容跨时间关联并对齐。图像向量与文本向量并非简单“只比较夹角”就能完成所有视觉理解，本节只是机制直觉。

## 总体主线

**Transformer 的位置与关系建模 → 自回归生成和训练阶段 → 运行时上下文与外部检索 → 视觉、听觉与时序信息变成模型可处理的特征。**视频把很多机制连续讲解，阅读时应保留它们的各自职责，不能把所有能力都归为“下一词预测”这一句话。
