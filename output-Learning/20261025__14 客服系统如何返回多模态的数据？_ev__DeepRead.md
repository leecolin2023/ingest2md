# Deep Read｜讲者如何从文本检索扩展到图片和视频

> 来源：`output/20261025__14 客服系统如何返回多模态的数据？_ev/content.md`（1分45秒），Deep Read V6.4。

讲者回顾已经介绍过的电商客服整体流程，然后聚焦简历中“接入素材中心，实现文字、图片、视频混排返回”的一句话，解释它并不一定需要复杂的直接视觉检索。

第一步仍是**意图识别**：辨别用户要文本、图片或视频。第二步是 Query 改写和检索：根据请求选择相应素材类型进行搜索。

讲者强调之前设计的三类数据记录其实有相似结构：商品关联信息、文本描述、由描述转出的 Embedding。与普通文本相比，图片、视频记录还要有可向前端返回的 URL。系统先根据图片或视频的**文字说明**匹配用户查询，找到素材记录后再返回媒体 URL。

这节课尤其明确了能力边界：**当前方案不是直接解析图片内容，也不是直接理解视频画面**，而是对媒体描述做文本语义检索。看起来是多模态内容返回，但检索索引本质上仍由文字驱动。
