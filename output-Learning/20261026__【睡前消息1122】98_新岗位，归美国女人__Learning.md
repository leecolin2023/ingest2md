# 如何正确阅读“98% 新增岗位属于女性”，以及 AI Agent 为什么冲击广告模式？

> 学习依据：《睡前消息1122》原稿。重点解释统计口径、产业就业机制和数字平台商业模式，不将节目中的具体数据视为已核实事实。

## 一、先确定“98%”的分母是什么

一个月新增岗位中女性占 98%，并不等于全体就业者有 98% 是女性。前者是**流量**，后者是**存量**。假设某月新增 100 个岗位，其中 98 个由女性获得，但原有就业总人数已经有 1 亿人，那么当月新增对总体性别比例的影响极小。

还要区分就业人数变动、岗位变动、季节性调整、调查修订，以及“净增岗位”和“新招岗位”。在不同指标之间跳跃，会把短期波动误认为长期趋势。分析时至少比较连续多个月的数据、男性和女性的就业率/劳动参与率、行业净增减与工资变化。

## 二、产业结构怎样影响不同人群的就业？

行业内部原本就存在不同的性别分布。若护理行业扩张、制造业萎缩，即使每个行业内部的性别比例不变，总体新增岗位的性别比例也会变化。这是**产业结构效应**。若同一行业内部雇佣结构也变化，则还有行业内部效应。

医疗养老需求与人口年龄结构相关，制造、交通、建筑则与固定资产投资、住房需求、国际贸易、劳动生产率有关。不能简单推断 AI 是所有裁员的直接原因；还需区分需求低迷、利率、企业调整及自动化的贡献。

## 三、AI 对工作为何可能同时创造与替代？

技术可以替代某个任务，也可能降低产品成本、提高产量并产生新的工作。最终净就业变化取决于被替代任务占多大比例、需求是否随成本下降扩大、企业是否创造新服务、劳动者能否转岗。单凭“模型能写代码”无法推出程序员总就业必然下降，更不能把资本支出增加直接当成净就业增加。

## 四、AI Agent 为什么与传统流量平台有利益冲突？

传统 App 的商业路径是：吸引用户→产生停留和互动→展示广告、推荐商品或收费。AI Agent 的路径可能变成：用户给定目标→跨服务读取信息和执行操作→只返回结果。用户的时间成本下降，但原有广告展示机会减少。

平台对外部 Agent 的限制可能同时涉及隐私、账号安全、交易责任、接口成本、反作弊和竞争策略。不能把所有限制都解释为恶意垄断；也不能因为存在安全问题就否认平台可能保护商业利益。

未来可考虑付费 API、按交易分成、Agent 订阅、授权数据访问等模式，让自动化节省的时间与平台服务成本重新匹配。节目真正引出的长期问题是：**当注意力不再是必要的价值交换媒介，数字服务如何收费？**
