## 岗位和个人背景

应聘者以跨境 3C 电商六年工作经历开场，讲到独立站和海外销售，也介绍前后端、AI 实时语音客服、RAG 数据整理、模型微调以及自媒体图片生成。面试官并非只考某个算法，而是反复追问：为何从深圳回武汉、公司效益怎样、本人可承担多少经营责任、是否能为真实电商业务赚钱。

## 电商 AI 产品的具体流程

双方讨论如何通过商品素材与市场参考图生成平台详情页、宣传主图，之后人工评审，未来再接自动上架接口。面试官追问：生成图片不代表每张可用，模型 API 费、视频费与运营人员审核成本都要计入利润。十张只用一张的实际单张可用成本，不能照生成 API 的单次报价计算。

面试官关心候选人是否以“可出售的商品和利润”为导向，而不是只是不断生成图片。候选人认为应该优先处理利润最高、复用最多的产品，不值得为低利润 SKU 无限制投入生成成本。这成为双方共同讨论的重点。

## RAG 客服的有效性问题

候选人讲到历史对话清洗、知识库、测试集和参考答案，声称在模型或提示词变更后运行回归。面试官并不满足“功能可以跑”，继续关注模型生成错误、人工审核、运营效率和产品是否真的能帮助销售。

## 薪酬与角色分歧

后半段对话转向城市、薪酬、工作强度、部门资源与岗位期望。应聘者对武汉 25K 与自身市场价值进行谈判，面试官反复强调公司在乎投入产出，并讨论未来涨薪机制。交谈后应聘者向直播观众展示其获得积极的口头回应，但材料不足以证明已经收到正式书面录用通知。

后续直播大量解释学员求职方法、课程价格、培训案例和招生，有明显促销目的，也伴随行业工资与培训成功率的口头推断，不是客观就业研究。
