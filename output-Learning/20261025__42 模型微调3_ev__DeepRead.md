# Deep Read｜LoRA 与 QLoRA 显存使用的区别

> 来源：output/20261025__42 模型微调3_ev/content.md（2分39秒），Deep Read V6.4。

讲者为了说明本地与云端的资源区别，介绍 LoRA 和 QLoRA。本地显卡可能只有 8～16GB 显存，直接对大模型进行常规微调成本较高，因此他建议本地采用量化底座的 QLoRA，云端资源较多时采用 LoRA。

他把 LoRA 比作房子局部装修，不必推倒整个模型重建；把 QLoRA 的额外特点解释为将底座模型权重从 16-bit 等较高精度变成 4-bit 存储，从而大幅减少显存占用。

原文还说 LoRA 近似无损、QLoRA 带轻微损失。这是帮助建立直觉的口头描述，不是经过同样测试集比较的精度结论。

主线是：全参数训练较贵 → LoRA 使用较少可训练参数 → QLoRA 在冻结底座上再量化 → 小显存本地验证更容易实现。
