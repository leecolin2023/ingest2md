# Deep Read｜什么是 Agent Skills：一次课程与项目讨论

> 来源：output/20261025__09 1.27回放 什么是Skills/content.md（约22分05秒）。Deep Read V6.4，按主题恢复。

讲者围绕新近流行的 Skills 能力讨论：为什么一个 Agent 只靠单条系统提示词难以稳定完成复杂专业任务，为什么需要将某类可复用操作组织成明确的技能文件、参考资料和执行步骤。Skill 在课程里被视为一种“给模型配置做某事的专业方法”的工程组织形式。

他还讨论 Skill 与 MCP、Function Calling、工具调用以及普通提示词的关系：Skill 提供工作方法和必要上下文，MCP 或 API 工具则提供外部能力；有时技能包含脚本或工具调用说明，但不是简单地把所有东西叫工具就可以替代技能。

围绕实现，他提到可以将 Markdown 形式的技能文件放入项目目录，模型在需要时读取相关指令，再执行多步流程；与其把几十种场景全部写进同一个系统提示词，不如在任务确定后按需加载相关 Skill。

讲者把这些技术与 AI 编码、课程实践和工作场景联系起来，鼓励学员通过实际项目去理解而非停留在名词。他也夹杂了有关行业变化和学习节奏的个人评价，不能由视频推出某一种 Skill 组织方式已经成为所有框架的标准。

全篇重点是**技能说明的可复用性与按需加载**；不是声称 Skill 文件本身可以自动执行外部动作。
