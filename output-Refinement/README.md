# Output Refinement｜转写稿忠实整理

本目录与 `output/` 同级，保存借助 [Transcript Refinement V0.1](https://github.com/leecolin2023/skill-repository/tree/main/skills/transcript-refinement) 规则整理的派生可读稿。原始文件均保持不变。


> **增量更新（2026-10-22）**：在原有 17 篇基础上，新增四篇经全文语义整理的可读稿：《思考程度》《Agent 高并发》《推理引擎》《本地部署》。新增稿件保留原始采集日期文件名、来源链接和逐段时间标记，不覆盖 output 原始内容。部分硬件性能、模型参数等说法属于视频作者观点，未经技术事实核查；没有核听音频。

> **增量更新（2026-10-23）**：本次比对 `output/` 与 `output-Refinement/` 后，补齐 6 篇新增转写稿（4 篇短视频 + 2 篇长播客）。沿用 `skills/transcript-refinement/SKILL.md` 规则，原始文件不变。短视频做了高置信术语、断句和结构清理；长播客主要进行保守的高置信词汇纠正、英文格式与段落整理，保留原始时间窗、数字与节目资料。**未经音频核听、未经独立事实核查，长播客也不等同于逐字人工精校。**

## 整理范围与局限

- 已逐篇覆盖 `output/` 中的 **27 篇内容正文**；`sources.md` 是采集记录索引，不属于正文，故未转换。
- 本批为保守文本整理：依据全文上下文进行部分高置信术语修复、跨切片句子修复、段落重排、少量主题标记。保留原作者论述顺序、数字、语气和原时间窗，不生成摘要。
- 未调用新的音频识别服务，也未核听音频。文本歧义、人物归属、长播客自动字幕中的部分错词仍须人工核查。此次并非完整逐句人工校对或逐篇深度语义重写。
- 特别是超过四小时的自动字幕，原稿缺乏准确标点与说话人划分：本次采用保守段落化，不能把段落分隔当成精确时间戳或人工听写验证。

## 命名

遵循主项目规则 `YYYYMMDD__标题.md`，使用原始稿记录的转写/处理时间换算到北京时间，作为已有稿件采集日的代理值；只截断文件名显示标题，不截断正文标题；含 `.md` 的文件名最多 **150 个 UTF-8 字节**，不追加 HHMMSS 或来源 ID。纯 Markdown 放在本目录，不需要额外 `content.md` 附件目录。
